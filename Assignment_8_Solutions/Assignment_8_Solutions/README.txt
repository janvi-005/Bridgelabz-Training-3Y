HOW TO RUN
1. Install Node.js, if it is not already installed.
2. Open Command Prompt or Terminal in this folder.
3. Run a file using:
   node Q1_Student_Result_Processing.js
4. Replace the filename with the question file you want to run.

NOTES
- Each question is in a separate JavaScript file.
- The code includes comments for easier understanding.
- Q1's assignment does not specify grade boundaries. This solution uses:
  A = 80 and above, B = 60-79.99, C = 40-59.99, F = below 40.
- Q5 uses an example fare rate of Rs. 12 per kilometre because the
  assignment does not specify a fare rate.
