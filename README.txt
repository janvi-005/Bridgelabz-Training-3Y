JAVASCRIPT ASSIGNMENT 6 – SOLUTIONS

This folder contains one JavaScript file for each of the 10 questions.

How to run:
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run a file using: node Q1_async_coffee_maker.js
4. Replace the filename with the question file you want to run.

Notes:
- Q1, Q3, Q4, Q7, Q8 and Q10 include random success/failure behavior,
  so output can differ each time you run them.
- Q5: runWithCallbacks() is enabled by default. To test async/await,
  comment out runWithCallbacks() and uncomment runWithAsyncAwait().
- Q6 uses the Fake Store API and requires an internet connection.
  Its optional HTML card section runs in a browser when an element with
  id="product-container" exists. In Node.js, the console output works
  in versions that support fetch.
- Q2 and Q9 demonstrate the event loop and include expected output order.

All solutions use core JavaScript (ES6+) and include explanatory comments.
